# mikehatchi.github.io

Michael John Hatchi's site: machine learning, distributed systems and confidential computing (FHE).

**Live: https://mikehatchi.github.io**

Travis, an AI agent with Mike's avatar, presents his projects and answers visitors' questions about his path, his projects and his skills, in English or French.

- A static site: HTML, CSS and plain JavaScript, no framework, no build step.
- Travis answers through a Cloudflare Worker (Workers AI). Each statement is checked against Mike's sources before it is shown; what the sources don't establish, Travis says so.
- No cookies, no analytics; visitors' conversations are not stored.
